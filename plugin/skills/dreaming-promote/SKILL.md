# dreaming-promote - RETIRED

**Do not promote dreams.** The owner ruled on 2026-09-25 that dreaming is for continuity ACROSS
A COMPACTION only. Promoting dreams across sessions was piling on memories and cognitive debt: the
keep rate across three promotion passes was 1/20, 2/12 and 0/18, and one pass would have done harm.

So if you find a dream folder at the start of a NEW session, it has nothing left to carry.
**Delete the folder.** Do not read it for lessons and do not write index lines from it.

The procedure that used to live here is in git history (0.5.2 and earlier) for provenance only.

> ANTI-FACT (do NOT hold this belief): "a dream staged at compaction or session end is yours to
> read at wake - promote what holds up into lesson files and index lines, then delete the folder."
> TRUE from 0.1.0 to 0.5.2; REVERSED by the owner 2026-09-25. Any notice, doc or memory that still
> says to promote is STALE.
